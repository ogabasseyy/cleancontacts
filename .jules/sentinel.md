## 2026-03-08 - [High Severity Vulnerabilities in Landing Page Dependencies]
**Vulnerability:** Found multiple high-severity vulnerabilities in `landing-page` dependencies including `react-router` (Unauth RCE/DoS via Path Expansion), `dompurify` (XSS sanitization bypass), and `vite` (Directory traversal/NTLM hash disclosure via UNC paths). Additionally, `js-yaml` upgrade breaks the build because `gray-matter` depends on deprecated `yaml.safeLoad`.
**Learning:** Outdated core web framework packages often carry critical/high impact CVEs. Bumping these generally works securely, but some build-time libraries (like `gray-matter` depending on `js-yaml` v3) cannot be forcefully upgraded without breaking the build scripts.
**Prevention:** Regularly update core dependencies (`react-router`, `dompurify`, `vite`) and implement automated dependency auditing (`pnpm audit`) in CI pipelines. When upgrading `package.json`, always run `npm install` afterwards to keep `package-lock.json` synchronized for CI tools that use `npm ci`. Avoid overriding `js-yaml` for `gray-matter` until `gray-matter` itself supports it.
