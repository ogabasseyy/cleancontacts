# Contacts Cleaner Privacy Policy

Privacy page: https://contactscleaner.tech/privacy

Effective date shown on site: October 2023

## Introduction

Contacts Cleaner describes privacy as central to the product. The policy says the app is designed to keep sensitive information on-device whenever possible.

## Information Collected

### Contact Data

The app requests access to the device contact list in order to identify duplicates, incomplete entries, and related address-book cleanup issues.

### Device Information

The site says technical data such as device model, OS version, and device identifiers may be collected to improve app performance.

## How Data Is Used

- Identify and merge duplicate contacts.
- Remove empty or invalid contact entries.
- Format phone numbers consistently.
- Back up contacts if the user explicitly opts in.
- Improve recognition and cleanup quality.

## Security And Storage

The public privacy page states that contact data is processed locally on-device using on-device machine learning and that full contact lists are not uploaded unless the user initiates a cloud backup feature.

## User Rights

The site states that users can:

- Request access to processed data.
- Request deletion of account-related data.
- Revoke contact permissions in device settings.
