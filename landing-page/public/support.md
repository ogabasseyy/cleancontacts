# Contacts Cleaner Support

Support page: https://contactscleaner.tech/support

## Common Questions

### How does duplicate detection work?

Contacts Cleaner uses fuzzy matching across names, phone numbers, and emails. Potential matches above an 82% similarity score are flagged as duplicates for review.

### Is data safe?

The public site states that contact processing happens locally on the device and that the address book is not uploaded to external servers for processing unless the user explicitly opts into cloud backup.

### Can changes be undone?

The support page says that every merge or delete action creates a snapshot and that changes can be rolled back from the in-app history.
